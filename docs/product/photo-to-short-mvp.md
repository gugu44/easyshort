# 사진 → 숏폼 MVP 화면 기획

## 1. MVP 목표

로그인한 개인 사용자가 사진 여러 장과 대본을 기반으로 9:16 세로 숏폼 영상을 생성합니다. 이 기능은 영상 분석이 필요 없고, 무료 테스트가 가능하며, 이후 영상 기반 기능의 편집기와 렌더링 구조를 재사용할 수 있기 때문에 1차 MVP로 적합합니다.

## 2. 사용자 시나리오

사용자는 이메일 로그인 후 개인 대시보드에서 새 프로젝트를 만들고 `사진으로 숏폼 만들기`를 선택합니다. 사진을 업로드한 뒤 직접 대본을 입력하거나 AI 대본 생성을 사용합니다. 이후 음성, 자막 스타일, 전환 효과를 선택하고 미리보기를 확인한 다음 MP4 파일로 다운로드합니다.

## 3. 화면 흐름

```txt
/login
→ /dashboard
→ /projects/new
→ /projects/:projectId/photos/upload
→ /projects/:projectId/script
→ /projects/:projectId/voice
→ /projects/:projectId/captions
→ /projects/:projectId/editor
→ /projects/:projectId/render
→ /projects/:projectId/result
```

## 4. 화면별 상세 기획

### 4.1 로그인/온보딩

#### 목적

B2C 사용자 계정을 만들고 개인 워크스페이스로 진입합니다.

#### 주요 요소

- 이메일 매직링크 로그인
- Supabase Auth 설정 안내
- 무료 플랜 혜택 안내
- 로그인 후 원래 요청했던 보호 페이지로 복귀

### 4.2 대시보드

#### 목적

프로젝트 목록을 확인하고 새 프로젝트를 시작합니다.

#### 주요 요소

- 상단 사용자/플랜 사용량 카드
- `새 프로젝트 만들기` 버튼
- 로그인 사용자 소유의 프로젝트 카드 목록
- 상태 필터: 전체, 작성 중, 렌더링 중, 완료, 실패

#### 프로젝트 카드 정보

- 썸네일
- 프로젝트명
- 프로젝트 타입
- 상태
- 최근 수정일
- 이어서 편집 버튼
- 다운로드 버튼

### 4.3 새 프로젝트 선택

#### 목적

제작할 숏폼 생성 방식을 선택합니다.

#### 카드 목록

- 롱폼 영상으로 숏폼 만들기
- 기존 숏폼 재가공
- 사진으로 숏폼 만들기
- 일반 영상 편집
- 대본으로 숏폼 만들기

#### MVP 처리

MVP에서는 `사진으로 숏폼 만들기`만 활성화하고 나머지는 `준비 중` 상태로 표시합니다.

### 4.4 사진 업로드

#### 목적

숏폼에 사용할 이미지를 업로드하고 순서를 정합니다.

#### 입력 조건

- 최소 3장
- 최대 10장
- 지원 형식: JPG, PNG, WebP
- 권장 비율: 자유, 최종 결과는 9:16으로 맞춤

#### 주요 기능

- 드래그 앤 드롭 업로드
- 업로드 진행률
- 썸네일 미리보기
- 순서 변경
- 삭제
- 이미지별 장면 길이 자동 배정

#### 다음 버튼 활성 조건

- 업로드 성공한 이미지가 3장 이상 있어야 합니다.

### 4.5 대본 작성

#### 목적

영상에 들어갈 내레이션/자막 대본을 작성합니다.

#### 탭 구성

- 직접 작성
- AI 대본 생성

#### 직접 작성 필드

- 제목
- 후킹 문장
- 본문
- CTA

#### AI 대본 생성 필드

- 주제
- 톤: 재밌게, 전문적으로, 감성적으로, 자극적으로
- 길이: 15초, 30초, 60초
- 타깃: 초보자, 직장인, 학생, 사업자
- CTA 포함 여부

#### 결과 처리

- 대본을 문장 단위로 분리합니다.
- 각 문장은 subtitle segment 후보가 됩니다.
- 사용자는 문장별로 수정할 수 있습니다.

### 4.6 음성 선택

#### 목적

대본을 읽어줄 음성을 선택하거나 음성 없이 자막만 사용할 수 있게 합니다.

#### provider 옵션

- 무료 테스트 음성
- 브라우저 TTS
- Typecast
- 추후 ElevenLabs/OpenAI TTS 추가 가능

#### 주요 요소

- provider 선택
- 목소리 선택
- 속도 조절
- 미리듣기
- 음성 생성 버튼

#### 예외 처리

- Typecast API Key가 없으면 `API 설정으로 이동` 버튼과 `무료 음성으로 테스트` 버튼을 함께 보여줍니다.

### 4.7 자막 스타일 선택

#### 목적

숏폼에 들어갈 자막 디자인을 설정합니다.

#### preset

- Bold Yellow
- White Caption
- TikTok Style
- Minimal
- News Style

#### 세부 옵션

- 위치: 상단, 중앙, 하단
- 폰트 크기
- 글자색
- 배경색
- 테두리
- 그림자
- 강조 단어 색상

### 4.8 편집/미리보기

#### 목적

사진, 대본, 음성, 자막을 하나의 타임라인에서 확인하고 수정합니다.

#### 레이아웃

```txt
좌측: 장면 리스트
중앙: 9:16 미리보기
우측: 선택 요소 속성 패널
하단: 타임라인
```

#### 편집 가능 요소

- 사진 순서
- 장면별 duration
- 자막 텍스트
- 자막 위치
- 전환 효과
- 음성 사용 여부
- BGM 사용 여부

### 4.9 렌더링

#### 목적

최종 MP4 파일 생성을 요청하고 진행 상태를 표시합니다.

#### 상태

- 대기 중
- 이미지 처리 중
- 음성 합성 중
- 자막 합성 중
- 영상 생성 중
- 완료
- 실패

#### 실패 시 제공 정보

- 실패 단계
- 에러 메시지
- 재시도 버튼
- 무료 provider로 다시 시도 버튼

### 4.10 결과

#### 목적

완성된 영상을 확인하고 다운로드합니다.

#### 주요 요소

- 영상 플레이어
- 다운로드 버튼
- 프로젝트 복제
- 다시 편집
- SRT/VTT 다운로드

## 5. MVP 데이터 구조

### 5.1 scene

```json
{
  "id": "scene_1",
  "assetId": "asset_1",
  "order": 1,
  "duration": 3,
  "transition": "fade",
  "motion": "zoom_in"
}
```

### 5.2 subtitle segment

```json
{
  "id": "sub_1",
  "start": 0,
  "end": 2.8,
  "text": "첫 문장입니다.",
  "stylePreset": "bold_yellow"
}
```

### 5.3 render input

```json
{
  "projectId": "project_1",
  "aspectRatio": "9:16",
  "resolution": {
    "width": 1080,
    "height": 1920
  },
  "scenes": [],
  "subtitles": [],
  "voiceAssetId": null,
  "captionStyle": "bold_yellow"
}
```

## 6. 완료 기준

사진 → 숏폼 MVP는 아래 조건을 만족하면 완료로 봅니다.

- 사용자가 사진 3장 이상을 업로드할 수 있습니다.
- 업로드된 사진 순서를 변경할 수 있습니다.
- 직접 대본을 작성할 수 있습니다.
- 대본이 자막 segment로 분리됩니다.
- 자막 스타일을 선택할 수 있습니다.
- 9:16 미리보기를 확인할 수 있습니다.
- 렌더링 결과 MP4를 다운로드할 수 있습니다.
- 무료 provider만으로 전체 플로우를 테스트할 수 있습니다.


## 7. B2C 사용자별 데이터 처리

- 프로젝트 생성 시 `user_id = auth.uid()`를 저장합니다.
- 사진 업로드 경로는 `users/{user_id}/projects/{project_id}/assets/{asset_id}` 형식을 사용합니다.
- 렌더링 결과는 동일 사용자 경로에 저장하고 signed URL로 다운로드합니다.
- 무료 플랜 한도 초과 시 업로드/렌더링 요청 전에 업그레이드 또는 다음 달 초기화 안내를 표시합니다.
- 삭제 요청은 프로젝트, 에셋, 렌더링 결과를 같은 `user_id` 범위에서만 처리합니다.
